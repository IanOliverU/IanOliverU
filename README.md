# こんにちは · 你好 · 初めまして · Hello 👋

I'm Ian, a **CMS Developer from the Philippines**, with experience building and maintaining Shopify and WordPress websites.

I'm currently expanding into **custom web and mobile development** with **React.js, Tailwind CSS, TypeScript, React Native, Expo, and Next.js**. Through personal projects, I'm strengthening my programming foundations and learning to build applications beyond CMS platforms.

My main personal project is **Project Akiha**, an AI desktop companion and personal assistant. I plan to extend her to my mobile devices and explore a **dedicated portable companion device**, potentially using ESP32-based hardware connected to my phone, so I can bring her beyond the desktop.

This GitHub documents my progress, experiments, and the things I learn along the way.

> [!TIP]
> Open to Shopify and WordPress projects, freelance work, and collaborations. My focus includes custom theme development, responsive implementation, and ongoing website support.
